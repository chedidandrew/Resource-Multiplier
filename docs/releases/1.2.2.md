# Smart Resource Multiplier 1.2.2

Status: source candidate, not yet tagged as a published release.

## Changed

- Renamed the public project from **Resource Multiplier** to **Smart Resource Multiplier**.
- Updated Fabric metadata, Mod Menu and configuration titles, reset prompts, command and diagnostic headers, issue forms, contribution guidance, documentation, tests, validators, and packaging copy.
- Changed newly built JAR names from `resource-multiplier-<version>.jar` to `smart-resource-multiplier-<version>.jar`.
- Changed deterministic release-package prefixes from `ResourceMultiplier-*` to `SmartResourceMultiplier-*`.
- Added a dedicated rebrand and upgrade-compatibility document.
- Preserved the existing icon for separate review rather than modifying binary artwork during the source and metadata transition.

## Compatibility

The Fabric mod ID remains `smart_resource_drops`. The configuration path, schema, datapack and network namespace, saved placement provenance, Java package, `/smartdrops`, and `/smartdropsgui` remain unchanged. Existing worlds and configurations require no migration.

Players upgrading from `1.2.1` should remove `resource-multiplier-1.2.1.jar` before adding `smart-resource-multiplier-1.2.2.jar` so only one JAR declares the stable mod ID.

## Scope

This patch changes branding, metadata, artifact names, documentation, and regression contracts only. It does not change block drops, entity death loot, XP, shearing, filters, multipliers, configuration defaults, networking, permissions, persistence, or anti-duplication behavior.

## Publication gate

`release_ready=false` remains in source until the final clean-checkout validation run and release decision are recorded. The latest published binary remains `1.2.1` until a `v1.2.2` tag and guarded release workflow complete.
