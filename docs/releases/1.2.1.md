# Resource Multiplier 1.2.1 release record

Resource Multiplier `1.2.1` is a metadata and storefront patch for the stable Fabric 26.2 line.

## Changes

- Mod Menu Website opens the official CurseForge project.
- Mod Menu Issues opens GitHub Issues.
- Source code remains linked to GitHub.
- Optional Ko-fi, PayPal, and Cash App support links are available in Mod Menu and GitHub funding metadata.
- Gameplay and configuration behavior are unchanged from `1.2.0`.

- Mod ID and datapack namespace: `smart_resource_drops`
- Config path: `config/smart_resource_drops.json`
- Commands: `/smartdrops` and `/smartdropsgui`
- Java package: `com.chedidandrew.smartresourcedrops`
- Schema 3 configuration and existing migrations
- Saved-world placement provenance and network identifiers
