# Smart Resource Multiplier 1.3.2 for Minecraft 1.21.5

This release brings the complete Smart Resource Multiplier experience to Minecraft 1.21.5 on both Fabric and NeoForge.

> Minecraft 26.2 remains the newest release and the default version shown on the repository. Use these files only with Minecraft 1.21.5.

## Highlights

- The same block, entity-drop, mob-XP, shearing, configuration, command, and anti-duplication features as the newer release line.
- Clearer block-XP wording and centered multiplier values throughout the configuration screens.
- Fixed repeated text in configuration tooltips while keeping useful extra details.
- Tested with loader-native client, server, persistence, and packaged-file checks.

## Downloads

- **Fabric:** `smart-resource-multiplier-1.3.2+mc1.21.5.jar`
- **NeoForge:** `smart-resource-multiplier-neoforge-1.3.2+mc1.21.5.jar`

Install only the file for your loader. Fabric users also need Fabric API. Back up worlds before changing Minecraft versions or mod loaders.
