# Smart Resource Multiplier 1.3.1 for Minecraft 1.21.1

This small patch improves the in-game configuration menu on both Fabric and NeoForge.

> Minecraft 26.2 remains the newest release and the default version shown on the repository. Use these files only with Minecraft 1.21.1.

## What changed

- Multiplier numbers are now properly centered between the minus and plus buttons.
- Fabric and NeoForge continue to use the same settings and gameplay behavior.
- No configuration reset or world restart is required when updating from 1.3.0.

## Downloads

Choose exactly one file for your loader:

- **Fabric:** `smart-resource-multiplier-1.3.1+mc1.21.1.jar`
- **NeoForge:** `smart-resource-multiplier-neoforge-1.3.1+mc1.21.1.jar`

Do not install both files in the same Minecraft instance. Fabric also requires Fabric API. Back up important worlds before changing Minecraft versions or mod loaders.
