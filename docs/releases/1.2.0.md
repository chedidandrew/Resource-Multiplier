# Resource Multiplier 1.2.0 release record

Resource Multiplier `1.2.0` promotes the manually validated `1.2.0-rc.1` candidate without gameplay changes.

The maintainer confirmed the supported block, entity death-loot, XP, shearing, GUI, multiplayer, persistence, migration, reload, command, and high-output checks passed.

The mod ID and datapack namespace remain `smart_resource_drops`; the config path remains `config/smart_resource_drops.json`; commands remain `/smartdrops` and `/smartdropsgui`.

The stable JAR is rebuilt as `resource-multiplier-1.2.0.jar`. Renaming the release-candidate JAR is not valid because embedded metadata and checksums would remain stale.

Third-party compatibility remains case-specific and should be reported with exact project versions.
