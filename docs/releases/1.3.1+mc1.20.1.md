# Smart Resource Multiplier 1.3.1 for Minecraft 1.20.1

This small patch improves the in-game configuration menu on both Fabric and NeoForge.

> Minecraft 26.2 remains the newest release shown on the main repository page. Use these files only with Minecraft 1.20.1.

## What changed

- Scrollbars in configuration subcategories now appear on the right side where expected.
- Multiplier numbers are now properly centered between the minus and plus buttons.
- Fabric and NeoForge continue to use the same settings and gameplay behavior.
- No configuration reset or world restart is required when updating from 1.3.0.

## Downloads

Choose exactly one file for your loader:

- **Fabric:** `smart-resource-multiplier-1.3.1+mc1.20.1.jar`
- **NeoForge:** `smart-resource-multiplier-neoforge-1.3.1+mc1.20.1.jar`

Install only the file for your loader. Fabric also requires Fabric API. Do not place both JARs in the same mods folder.
