# Smart Resource Multiplier 1.3.2 for Minecraft 1.21.6-1.21.8

This release brings Smart Resource Multiplier to Minecraft Java Edition
1.21.6, 1.21.7, and 1.21.8 on Fabric and NeoForge.

> Minecraft 26.2 remains the newest release and the default version shown on
> the repository. Use these files only with Minecraft 1.21.6 through 1.21.8.

## What changed

- Added thoroughly tested Fabric and NeoForge support across all three
  Minecraft versions.
- Kept the same multipliers, placement protection, entity drops, shearing,
  commands, presets, and in-game configuration experience on both loaders.
- Fixed configuration tooltips that could repeat a row's title and description.
- Kept clipped-row details available while showing each tooltip line only once.
- Preserved existing settings, worlds, and the `smart_resource_drops` mod identity.

## Downloads

Choose exactly one file for your loader and Minecraft version:

- **Fabric 1.21.6-1.21.8:**
  `smart-resource-multiplier-1.3.2+mc1.21.6-1.21.8.jar`
- **NeoForge 1.21.6:**
  `smart-resource-multiplier-neoforge-1.3.2+mc1.21.6.jar`
- **NeoForge 1.21.7-1.21.8:**
  `smart-resource-multiplier-neoforge-1.3.2+mc1.21.7-1.21.8.jar`

Fabric also requires the matching Fabric API. Do not install more than one
Smart Resource Multiplier JAR in the same Minecraft instance. Back up important
worlds before changing Minecraft versions or mod loaders.
