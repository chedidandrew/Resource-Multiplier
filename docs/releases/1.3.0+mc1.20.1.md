# Smart Resource Multiplier 1.3.0 for Minecraft 1.20.1

Smart Resource Multiplier is now available for Minecraft Java Edition 1.20.1 on both Fabric and NeoForge.

> Minecraft 26.2 remains the newest release shown on the main repository page. Download this backport only for a Minecraft 1.20.1 instance.

## What players get

- The same block, ore, crop, entity-drop, mob-XP, and supported shearing multiplier features on both loaders.
- The complete in-game configuration menu, including populated Entity Categories, searchable overrides and filters, presets, and reset confirmation.
- Clear **Multiply Block XP** wording on the main screen; mob XP remains separately configurable under Entity Drops.
- Smart placement protection, explosion and automated-mining controls, output safety limits, and multiplayer operator permissions.
- Compatibility with the existing `smart_resource_drops` configuration identity and schema 3 settings.
- A safer fragmented configuration connection for the smaller network-packet limit used by Minecraft 1.20.1.

## Choose one file

- **Fabric:** `smart-resource-multiplier-1.3.0+mc1.20.1.jar`
- **NeoForge:** `smart-resource-multiplier-neoforge-1.3.0+mc1.20.1.jar`

Install only the file for your loader. The Fabric build also requires Fabric API. Do not place both JARs in the same mods folder.

## Requirements

- Minecraft Java Edition 1.20.1
- Java 17
- Fabric Loader 0.19.5 and Fabric API 0.92.12+1.20.1, or NeoForge 1.20.1-47.1.106

Back up important worlds before changing loaders or mod sets. The two builds preserve the same public mod ID, commands, configuration filename, and datapack namespace, but this release does not claim automatic conversion between loader-specific saved chunk data.
