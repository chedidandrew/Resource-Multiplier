# Smart Resource Multiplier 1.3.0 for Minecraft 1.21.1

This backport brings Smart Resource Multiplier 1.3.0 to Minecraft Java Edition 1.21.1 on both Fabric and NeoForge.

> Minecraft 26.2 remains the newest release and the default version shown on the repository. Use this file only with Minecraft 1.21.1.

## What is included

- Configurable block drops, entity drops, mob XP, and Sheep shearing multipliers.
- The same in-game configuration screens, including the clear **Multiply Block XP** label.
- Placement protection, output safety limits, commands, presets, filters, and multiplayer permissions.
- Separate native builds for Fabric and NeoForge.
- Minecraft 1.21.1 and Java 21 compatibility.

For safety on this older target, supported shearing multiplication is intentionally limited to vanilla Sheep. Other special vanilla shearing rewards remain `1x`.

## Downloads

Choose exactly one file for your loader:

- **Fabric:** `smart-resource-multiplier-1.3.0+mc1.21.1.jar`
- **NeoForge:** `smart-resource-multiplier-neoforge-1.3.0+mc1.21.1.jar`

Do not install both files in the same Minecraft instance. Fabric also requires Fabric API. Back up important worlds before changing Minecraft versions or mod loaders.

## Compatibility

Both builds keep the existing `smart_resource_drops` identity, schema 3 configuration, commands, datapack namespace, and multiplayer authority model. Configuration files remain compatible, but Minecraft world downgrades and repeatedly switching a world between loaders are not supported.
