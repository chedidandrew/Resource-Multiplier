# Smart Resource Multiplier 1.3.0

Smart Resource Multiplier `1.3.0` is the first release that supports both Fabric and NeoForge for Minecraft Java Edition 26.2.

## Choose your download

- Fabric: `smart-resource-multiplier-1.3.0.jar`
- NeoForge: `smart-resource-multiplier-neoforge-1.3.0.jar`

Install only the file made for your mod loader. Fabric also requires Fabric API. Never put both Smart Resource Multiplier JARs in the same Minecraft instance.

## What players will notice

- NeoForge players now receive the same block-drop, mob-loot, mob-XP, shearing, filtering, category, override, command, and configuration-screen features as Fabric players.
- The previously empty NeoForge Entity Categories page now displays and configures all nine categories correctly.
- The General-screen controls now say **Multiply Block XP** and **Block XP Multiplier**, making it clear that mob XP is configured separately under **Entity Drops**.
- Multiplayer configuration remains controlled by the server. Operators can apply changes and other players can safely view the current settings.
- The approved high-resolution Smart Resource Multiplier icon is included in both loader files.

## Existing worlds and settings

The mod keeps its existing `smart_resource_drops` identity, schema 3 configuration file, commands, datapack namespace, and configuration keys. Updating a Fabric installation from `1.2.3` does not require resetting the configuration.

Fabric-to-NeoForge placed-block protection migration is supported and tested, but it is intentionally one-way because the two loaders store that chunk data differently. Back up a world before changing loaders, and do not repeatedly move the same world back and forth between Fabric and NeoForge.

## Release checks

Both JARs are rebuilt from the same stable source and validated separately. The release checks cover shared unit and gameplay tests, dedicated-server loading, the real configuration GUI, multiplayer permissions and reconnects, optional client/server installation combinations, malformed network input, loader isolation, packaging, and the captured Fabric-world migration path.

CurseForge remains the player download page. GitHub contains the matching stable source and verification records.
