# Smart Resource Multiplier 1.2.3

Status: stable public release for Minecraft Java Edition 26.2 and Fabric.

## Changed

- Replaced the packaged production icon with the approved `512x512` **SMART RESOURCE MULTIPLIER** diamond-mining artwork.
- Preserved the canonical `assets/smart_resource_drops/icon.png` path used by Fabric metadata and Mod Menu.
- Declared a Java 25 Gradle toolchain with automatic detection and download fallback, allowing the wrapper to compile correctly when invoked from an installed Java 21 runtime.

## Compatibility

The Fabric mod ID remains `smart_resource_drops`. The configuration path, schema, datapack and network namespace, saved placement provenance, Java package, `/smartdrops`, and `/smartdropsgui` remain unchanged. Existing worlds and configurations require no migration.

Players upgrading from `1.2.2` must remove `smart-resource-multiplier-1.2.2.jar` before adding `smart-resource-multiplier-1.2.3.jar` so only one JAR declares the stable mod ID.

## Scope

This patch changes branding artwork, versioned documentation, and local build-toolchain selection only. It does not change block drops, entity death loot, XP, shearing, filters, multipliers, configuration defaults, networking, permissions, persistence, or anti-duplication behavior.

## Verification and publication

The release commit sets `release_ready=true`. Publication rebuilds the JAR from source and repeats package validation, deterministic packaging tests, Mod Menu and public-copy regressions, core assertions, mapped JUnit tests, all 66 dedicated-server GameTests, client GUI and authority GameTests, and the Java 25 Fabric build before creating the `v1.2.3` GitHub Release.
