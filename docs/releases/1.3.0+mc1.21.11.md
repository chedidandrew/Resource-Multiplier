# Smart Resource Multiplier 1.3.0 for Minecraft 1.21.11

This release brings the complete Smart Resource Multiplier 1.3.0 experience to Minecraft Java Edition 1.21.11 on both Fabric and NeoForge.

> Minecraft 26.2 remains the newest release and the default version shown on the repository. Use this backport only for a Minecraft 1.21.11 instance.

## What is included

- The same block, entity-drop, mob-XP, and supported shearing multipliers as the 26.2 version.
- The same in-game configuration screens, including the clearer **Multiply Block XP** label.
- The same placement protection, output safety limits, commands, presets, filters, and multiplayer permissions.
- Separate, native builds for Fabric and NeoForge.
- Compatibility adjustments for Minecraft 1.21.11 and Java 21.

## Downloads

Choose exactly one file for your loader:

- **Fabric:** `smart-resource-multiplier-1.3.0+mc1.21.11.jar`
- **NeoForge:** `smart-resource-multiplier-neoforge-1.3.0+mc1.21.11.jar`

Do not install both files in the same Minecraft instance. Fabric also requires Fabric API. Back up important worlds before changing mod loaders.

## Tested

Both builds are compiled and tested specifically against Minecraft 1.21.11. Automated checks cover resource multiplication, placement protection, entity loot and XP, shearing, commands, configuration screens, multiplayer authority, loader metadata, and release-JAR contents.

The mod keeps its existing `smart_resource_drops` identity and schema 3 configuration, so its settings, commands, datapack namespace, and multiplayer behavior stay consistent with the 1.3.0 feature release.
