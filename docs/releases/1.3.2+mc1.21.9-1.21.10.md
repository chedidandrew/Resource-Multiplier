# Smart Resource Multiplier 1.3.2 for Minecraft 1.21.9-1.21.10

This release brings the same Smart Resource Multiplier experience to Minecraft 1.21.9 and 1.21.10 on Fabric and NeoForge.

> Minecraft 26.2 remains the newest release and the default version shown on the repository. Use these files only with the Minecraft versions and loader named in each filename.

## What changed

- Added tested Fabric and NeoForge builds for Minecraft 1.21.9 and 1.21.10.
- Centered multiplier values correctly between the minus and plus buttons.
- Removed repeated titles and descriptions from configuration tooltips.
- Kept the same block, mob-loot, XP, shearing, safety, command, and configuration behavior across both loaders.
- Preserved existing schema 3 configuration files and the `smart_resource_drops` mod identity.

## Downloads

Choose exactly one file for your Minecraft version and loader:

- **Fabric 1.21.9-1.21.10:** `smart-resource-multiplier-1.3.2+mc1.21.9-1.21.10.jar`
- **NeoForge 1.21.9:** `smart-resource-multiplier-neoforge-1.3.2+mc1.21.9.jar`
- **NeoForge 1.21.10:** `smart-resource-multiplier-neoforge-1.3.2+mc1.21.10.jar`

Fabric also requires Fabric API. Do not install Fabric and NeoForge files together. Back up important worlds before changing Minecraft versions or mod loaders.
